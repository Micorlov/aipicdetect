    — How it works

    Three steps, nothing stored.

    1. 01

      Upload.

      Drop, paste or pick a picture. It is processed in memory by the picai server you are using: this public instance, or your own if you self-host.

    2. 02

      Detect.

      An open-source image classifier scores how likely the pixels were produced by a generator.

    3. 03

      Read the verdict.

      You get an AI likelihood, a confidence band and the metadata blocks the file carries — as a probability, not a verdict.

    — FAQ

    Questions people ask.

    How accurate is the detector?

    It reports a probability, not a verdict. Scores near 50% are labelled Uncertain; treat any single result as a signal and combine it with other evidence. Detectors degrade on newer generators: read what the benchmarks say.

    Does my image leave my computer?

    On this public instance, yes: the picture is uploaded to the picai server, scored in memory and never written to disk. The scrubbed copy is held in memory briefly so you can download it, then evicted. If you want nothing to leave your machine, run picai yourself with one Docker command.

    Is it open source?

    Yes. The code, the Docker image, the CLI and the GitHub Action are all in the picai repository. The detector is an open Hugging Face model you can inspect or replace.

    Can I remove C2PA and other metadata?

    Yes. After checking a picture, use Download clean copy. picai rebuilds the image from its pixels, so EXIF, XMP, IPTC, C2PA and the ICC profile are all left behind. More about content credentials.

    Which formats are supported?

    JPEG, PNG, WebP, HEIC/HEIF and most formats Pillow can decode, up to 50 MB.

    Why is metadata listed?

    C2PA content credentials and editing-software tags are provenance hints. The panel shows which blocks (EXIF, XMP, IPTC, C2PA, ICC) the file carries so you can weigh them alongside the score.

    Can I use a different model?

    Yes. Set PICAI_DETECTOR_MODEL to any Hugging Face image-classification model whose labels name AI/fake vs. human/real content.
