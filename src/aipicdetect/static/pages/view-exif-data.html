Upload any JPEG, PNG, WebP or HEIC file to view all of its embedded metadata — EXIF camera data, GPS coordinates, XMP copyright fields, IPTC captions, and C2PA content credentials — right in your browser, with nothing uploaded to a third-party server.

How to view the EXIF data in an image

  1. Open AiPicDetect.
  2. Drag your image into the dropzone, paste it from the clipboard, or tap "Choose photo" on mobile.
  3. Once the analysis completes, scroll to the Metadata section.
  4. Every block found in the file is listed: EXIF, XMP, IPTC, ICC colour profile, C2PA content credentials, and JPEG APP segments.

The metadata check takes under a second and runs entirely in the browser — your image is sent to the server only to run the AI detector, never to an external analytics service.

What each metadata type contains

EXIF
Camera make and model, lens, shutter speed, aperture, ISO, flash, orientation. Critically: GPS latitude and longitude if location sharing was enabled on the device that took the photo.
XMP
Adobe-defined fields used by Lightroom, Photoshop, and other editors: copyright notice, creator, rating, colour label, edit history, and — for AI-generated images — sometimes the prompt text.
IPTC
News-wire standard fields: byline, caption, keywords, city, country, copyright notice. Common in stock photos and news images.
ICC colour profile
The colour space embedded by the camera or editor (sRGB, Adobe RGB, Display P3). Not privacy-sensitive, but present in nearly all photos.
C2PA content credentials
A cryptographically signed provenance record that says who created the content and with what tool. DALL-E 3, Adobe Firefly, and some cameras embed these. See the C2PA page for details.

Remove metadata after viewing

If you find GPS coordinates, camera serial numbers, or other sensitive fields you want removed, AiPicDetect can strip all metadata by re-rendering the image from its pixels. The clean copy is available to download immediately — no account required. See how metadata removal works.
