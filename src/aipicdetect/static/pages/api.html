AiPicDetect exposes a small HTTP API: POST /analyze returns an AI likelihood plus a metadata report, POST /scrub returns a re-rendered copy of the image with every metadata block removed. No API key is needed. The hosted base URL is {{ORIGIN}}; a self-hosted server uses http://127.0.0.1:8000.

POST /analyze

Multipart upload (file field), up to {{MAX_UPLOAD_MB}} MB. Accepts JPEG, PNG, WebP, HEIC/HEIF and any other format Pillow can decode. Optional query parameters: format (jpeg, png or webp for the scrubbed copy) and quality (1–100, default 95).

curl -s -F "file=@photo.jpg" "{{ORIGIN}}/analyze?format=jpeg&quality=90"
{
  "id": "0f3c…",
  "download_url": "/download/0f3c…",
  "download_name": "photo.clean.jpg",
  "detection": {
    "ai_likelihood": 0.97,
    "percent": 97,
    "confidence": "High",
    "classification": "AI",
    "model": "{{MODEL}}"
  },
  "metadata": {
    "removed": {"EXIF": ["Exif\\u0000\\u0000"], "XMP": ["http://ns.adobe.com/xap/1.0/"]},
    "jpeg_app_segments": ["APP1", "APP1"]
  },
  "input": {"bytes": 2381912, "width": 4032, "height": 3024, "format": "JPEG"},
  "output": {"bytes": 1904331, "format": "JPEG", "media_type": "image/jpeg"},
  "quota": {"limit": {{DAILY_LIMIT}}, "remaining": 9, "window_hours": 24}
}
  • classification is AI, Real or Uncertain (within 10 points of 50%); confidence is High, Medium or Low. See how the score is computed.
  • metadata.removed lists every block found in the upload (EXIF, XMP, IPTC, C2PA, ICC) with the byte signatures that matched.
  • download_url serves the scrubbed copy until {{RESULT_CACHE_LIMIT}} newer results replace it or the server restarts; it is not written to disk.
  • quota is null when the daily limit is disabled.

POST /scrub

Same upload and query parameters; the response body is the scrubbed image itself, with Content-Disposition: attachment and an X-AiPicDetect-Removed header listing the blocks that were dropped. It is not subject to the daily limit.

curl -s -F "file=@photo.jpg" -o photo.clean.jpg -D - "{{ORIGIN}}/scrub" | grep -i x-aipicdetect-removed

Errors and limits

StatusMeaning
400Empty upload.
413Upload larger than {{MAX_UPLOAD_MB}} MB.
415The file could not be decoded as an image.
422Invalid format or quality.
429Daily limit reached ({{DAILY_LIMIT}} analyses per IP per 24 h on the hosted instance). Retry-After and X-RateLimit-Remaining headers are set.

Uploads are processed in memory and never stored; details on the privacy page. To run without limits, self-host AiPicDetect.
